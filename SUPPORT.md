# Support

## Use GitHub Discussions for

- “how do I verify this recovery behavior?” questions;
- integration ideas;
- compatibility reports;
- showcase/adopter stories.

## Use GitHub Issues for

- reproducible bugs;
- accepted feature proposals;
- documentation defects;
- compatibility regressions.

## Use private vulnerability reporting for

- security issues, secret exposure, policy bypass, profile/path escape, or unsafe matching.

A useful support request includes exact Node, DSH and dsh-autofix versions; operating system; the matched Recipe; `dsh-autofix verify --json` output; and the smallest reproduction. Raw logs are optional and must be redacted.
